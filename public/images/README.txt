Krishi Connect — Image Placeholders

Drop your real product photos into this folder using the exact filenames
below. The app will automatically pick them up — no code changes needed.

Expected filenames:
  tea.jpg      — Tea garden / tea leaves
               — Rice terraces / paddy field
               — Tomatoes
  wheat.jpg    — Wheat field
  onion.jpg    — Onions
  potato.jpg   — Potatoes
  crop.jpg     — Default fallback for any crop not listed above

For crops with custom names that don't match any of the above, the app
will look for a slugified filename (e.g. "Cauliflower" -> cauliflower.jpg).

If a file is missing, a labeled gray placeholder box with the expected
filename is shown instead, so you can see exactly which image is needed.
